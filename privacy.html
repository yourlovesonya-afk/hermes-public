Какие данные обрабатываются

Hermes обрабатывает сообщения и задания владельца, ссылки и названия таблиц, названия листов, выбранные значения ячеек, а также данные для создания новых таблиц. Для доступа к Google сохраняются технические данные OAuth: идентификатор клиента и токены доступа и обновления. Пароль Google-аккаунта приложение не получает.

Зачем нужен доступ к Google

Данные используются для выполнения конкретных запросов: прочитать таблицу, объяснить или структурировать её содержимое, создать новый файл с согласованными данными и вернуть ссылку.

  • Разрешение на чтение Google Таблиц позволяет открывать таблицы, доступные владельцу, по ссылке или идентификатору.
  • Разрешение на отдельные файлы Google Drive позволяет создавать новые файлы и работать с файлами, созданными приложением или явно предоставленными ему.

Подключённые инструменты не удаляют файлы, не меняют разрешения доступа и не редактируют ранее существовавшие таблицы. Создание новой таблицы требует подтверждения владельца.

Кому могут передаваться данные

Для выполнения запросов нужное содержимое таблиц может включаться в запросы к внешней языковой модели. В текущей установке используется провайдер OpenAI через подключённый аккаунт ChatGPT. Ответы и включённые в них данные передаются через Telegram. Google обрабатывает запросы к своим API. Обработка каждым сервисом регулируется его условиями и политикой конфиденциальности.

Владелец не продаёт данные Google, не использует их для рекламного профилирования и не использует их для обучения собственных моделей. Применение информации, полученной через Google API, ограничено пользовательскими функциями приложения и должно соответствовать Google API Services User Data Policy, включая требования Limited Use.

Хранение и защита

Настройки, память и история работы хранятся на сервере владельца. Фрагменты таблиц могут сохраняться в истории или памяти при выполнении задания. Резервные копии постоянных данных хранятся в приватном репозитории GitHub; доступы и токены исключаются из него. Секретные файлы имеют ограниченные права доступа. Доступ к серверу осуществляется через SSH, обращения к Google — по HTTPS.

Фиксированный срок автоматического удаления истории и резервных копий не настроен: они сохраняются до удаления владельцем. Эта публичная страница не содержит таблиц, истории общения или секретных данных.

Отзыв доступа и удаление

Владелец может отозвать доступ Hermes в разделе подключений Google-аккаунта. Отзыв прекращает дальнейший доступ, но сам по себе не удаляет ранее сохранённые данные и созданные таблицы.

Для удаления локальных токенов, памяти, истории или резервных копий следует обратиться по адресу yourlovesonya@gmail.com. Удаление выполняется владельцем с учётом истории версий резервных копий. Созданные таблицы можно удалить непосредственно в Google Drive. Сообщения Telegram и данные у внешних провайдеров управляются также средствами этих сервисов.

Данные посетителей этого сайта

Сайт размещён на GitHub Pages. На страницах нет форм, рекламных инструментов, собственных файлов cookie и аналитических скриптов. GitHub может обрабатывать технические сведения о посещениях согласно своей политике конфиденциальности.

Изменения политики

При изменении подключений или способа обработки данных эта страница обновляется; дата актуальной редакции указана в начале.
